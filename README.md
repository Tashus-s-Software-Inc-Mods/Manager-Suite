# Tashus Manager Suite

Automation mods for **Software Inc** that share one control panel. This repository is the public home for the
suite: player guides, the integration guide for other mod authors, and the place to report bugs and ask for
features.

**Report a bug or request a feature:** [open an issue](https://github.com/Tashus-s-Software-Inc-Mods/Manager-Suite/issues/new/choose). Every report asks which mod it
is about, so it reaches the right place.

## The mods

| Mod | What it does | Workshop |
|---|---|---|
| **Manager UI** | The shared Manager button and window. Required by the other mods. | [Subscribe](https://steamcommunity.com/sharedfiles/filedetails/?id=3739704295) |
| **Contract Manager** | Accepts contracts that match your rules and runs them from design to delivery. | [Subscribe](https://steamcommunity.com/sharedfiles/filedetails/?id=3737490722) |
| **Deal Manager** | Accepts Design, Development, Support, Marketing, Print and Hosting deals and works them on the teams you choose. | [Subscribe](https://steamcommunity.com/sharedfiles/filedetails/?id=3737533696) |
| **Leader Manager** | Keeps each chosen team staffed with the right leader, so auto-hiring and training never stop. | [Subscribe](https://steamcommunity.com/sharedfiles/filedetails/?id=3737789185) |
| **Research Manager** | Researches each year's new tech and files the patents on the teams you choose. | [Subscribe](https://steamcommunity.com/sharedfiles/filedetails/?id=3740631068) |
| **Investment Manager** | Invests spare cash in other companies' shares for dividends and growth. | [Subscribe](https://steamcommunity.com/sharedfiles/filedetails/?id=3739986889) |
| **Team Schedule Manager** | Cuts an idle team's work day and restores it when work arrives; can crunch a team near a deadline. | [Subscribe](https://steamcommunity.com/sharedfiles/filedetails/?id=3767459405) |
| **Furnish Manager** | Keeps rooms stocked with the fixtures and furniture they need. | Not on the Workshop yet |

The whole set is also in the [Manager Collection](https://steamcommunity.com/workshop/filedetails/?id=3737515068).

## Source code

The mod source ships with each Workshop item, as Software Inc compiles code mods from source when it loads them.
The development repositories are private; this repository holds the documentation and the issue tracker.
