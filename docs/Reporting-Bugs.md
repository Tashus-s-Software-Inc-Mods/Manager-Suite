# Reporting a bug

[Open an issue](https://github.com/Tashus-s-Software-Inc-Mods/Manager-Suite/issues/new/choose) and pick **Bug report**. The form asks for:

- **Which mod.** If more than one mod is involved, pick the one you were using and mention the others.
- **What happened and what you expected.** One or two sentences each is plenty.
- **Steps to reproduce**, if you know them.
- **Game version.** Shown on the game's main menu.
- **The log**, if there was an error.

## Where the log is

Software Inc writes `output_log.txt` in its install folder. For a default Steam install that is:

```
C:\Program Files (x86)\Steam\steamapps\common\Software Inc\output_log.txt
```

Steam can also open the folder for you: right click Software Inc in your library, then **Manage**, then
**Browse local files**.

The log is rewritten every time the game starts, so copy it right after the problem happens, before you start
the game again. Drag the file into the issue form to attach it, or paste the lines around the error.

## Before you post

Search the [open issues](https://github.com/Tashus-s-Software-Inc-Mods/Manager-Suite/issues) first. If your problem is already there, add a comment with your details
instead of opening a new one.

## Feature requests

Pick **Feature request** in the same place. Say which mod it is for and what you want to happen in game. A short
description of the situation where you missed it helps more than a proposed design.
