# Getting started

## Install

1. Subscribe to **Manager UI** on the Steam Workshop. Every other mod in the suite draws its settings into its
   window, so it is required.
2. Subscribe to the managers you want. Each one works on its own; you do not need the whole set.
3. Start Software Inc.

## Approve the code mods

Software Inc asks before it runs a code mod for the first time, and again after a mod's code changes. Open the
**Mods** window, go to the **Code mods** tab and approve each mod. A mod that is waiting for approval does
nothing and shows no errors, so this is the first thing to check if a manager seems idle.

## Find the Manager window

Load a game and click the **Manager** button. The window lists every installed manager on the left. Each one has
an on/off switch in its header and a status line saying what it is doing now. The **Overview** page shows all of
them at once, and the **Activity** page lists every action they took, newest first.

Some managers also add a tab to the game's **Manage Team** window, for settings that belong to one team.

## Settings and saves

Settings tied to a game (which teams a manager uses, per-team rules) are stored in the save. Settings that apply
to every game are kept in the mod's own settings file. Starting a new game does not carry the previous game's
team choices over.

## Game version

The mods are written for the current Software Inc beta. After a game update, Steam usually delivers a matching
mod update shortly after. If a mod stops working right after a game update, see
[Troubleshooting](Troubleshooting.md).
