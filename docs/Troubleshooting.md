# Troubleshooting

## A manager does nothing

- **Not approved.** Open **Mods**, then **Code mods**, and approve it. The game asks again after every update
  to a mod's code.
- **Switched off.** Check the switch in the manager's header in the Manager window. The Overview page shows
  every manager's state at once.
- **No teams chosen.** Most managers only act on teams you pick. The status line says when nothing is set up.
- **Nothing to do.** The Activity page shows skipped actions when "Show skipped" is ticked, with the reason.

## A manager says "Not responding"

The Manager window shows this when a mod has stopped reporting its status. Usually the game switched the mod off
after it threw an error. Check the **Code mods** tab: a mod the game turned off shows as disabled there. Turn it
back on and, if it happens again, [report it](Reporting-Bugs.md) with the game's log.

## The game shows a compile error for a mod

Software Inc compiles each code mod when it loads. After a game update a mod can stop compiling until it is
updated. Check the Workshop page for an update, then restart the game. If the error remains, report it with the
log.

## The Manager button is missing

Manager UI is not installed, not approved, or switched off. The other managers need it to show their settings.

## Still stuck

[Open an issue](https://github.com/Tashus-s-Software-Inc-Mods/Manager-Suite/issues/new/choose) and pick the mod it is about.
